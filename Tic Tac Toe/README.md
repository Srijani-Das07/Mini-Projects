# Tic Tac Toe

A classic two-player Tic Tac Toe game built using HTML, CSS, and JavaScript.  
Play against a friend directly in the browser with a clean and responsive interface.

---

## Features

- Two-player turn-based gameplay  
- Winner detection logic  
- Draw detection  
- Reset and New Game functionality  
- Clean and responsive UI  

---

## Tech Stack

- HTML  
- CSS  
- JavaScript  

---

## How to Run

1. Clone the repository:
   git clone https://github.com/Srijani-Das07/Mini-Projects.git

2. Open the Tic Tac Toe folder in Mini-Projects:
   cd Mini-Projects
   cd "Tic Tac Toe"

3. Run:
   Open `index.html` in your browser

## Usage

- Player X always goes first  
- Click any empty cell to place your mark  
- The game announces the winner or a draw automatically  
- Click Reset to restart the current game  
- Click New Game to start fresh
