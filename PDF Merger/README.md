# PDF Merger

A browser-based tool to merge multiple PDF files into one — no backend, no uploads, everything runs locally.

## Features

- Upload multiple PDF files via drag & drop or file browser
- Reorder files by dragging them before merging
- Remove individual files from the list
- Merges all PDFs and downloads the result instantly
- Runs entirely in the browser using pdf-lib
- Fully responsive — works on mobile too

## How to Run

Just open `index.html` in any modern browser. No installation needed.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- [pdf-lib](https://pdf-lib.js.org/) (via CDN)
