# 📄 PDF Merger (Advanced Web Version)

A modern PDF Merger built using HTML, CSS, and JavaScript.

---

## 🚀 Features

- Merge multiple PDFs
- Add files multiple times
- Drag & Drop upload
- File preview list
- Reorder PDFs (↑ ↓)
- Remove files
- Dark Mode toggle
- Works fully in browser (no backend)

---

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- pdf-lib

---

## 📦 Usage

1. Open `index.html`
2. Add PDFs (drag/drop or click)
3. Arrange order if needed
4. Click Merge
5. Download starts automatically
