# Password Generator

A simple and secure Password Generator built using HTML, CSS, and JavaScript.  
It allows users to generate strong passwords with customizable options.

---

## Features

- Generate secure passwords instantly  
- Copy password to clipboard  
- Password strength checker  
- Adjustable length slider  
- Responsive UI  

---

## Tech Stack

- HTML  
- CSS  
- JavaScript  

---

## How to Run

1. Clone the repository:
   git clone https://github.com/Srijani-Das07/Mini-Projects.git

2. Open the PasswordGenerator folder in Mini-Projects:
   cd Mini-Projects
   cd PasswordGenerator

3. Run:
   Open `index.html` in your browser

## Usage

- Adjust the length slider to set password length  
- Generated password appears automatically  
- Check the strength indicator for security level  
- Click Copy to copy the password to clipboard
