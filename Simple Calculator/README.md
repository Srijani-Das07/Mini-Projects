# Simple Calculator

A clean and responsive Simple Calculator built using HTML, CSS, and JavaScript.  
It performs all basic arithmetic operations with a minimal interface.

---

## Features

- Addition, subtraction, multiplication, division  
- Clear and delete functionality  
- Responsive and clean UI  
- Lightweight with no dependencies  

---

## Tech Stack

- HTML  
- CSS  
- JavaScript  

---

## How to Run

1. Clone the repository:
   git clone https://github.com/Srijani-Das07/Mini-Projects.git

2. Open the Simple Calculator folder in Mini-Projects:
   cd Mini-Projects
   cd "Simple Calculator"

3. Run:
   Open `index.html` in your browser

## Usage

- Click number buttons to enter values  
- Select an operator to perform the operation  
- Press = to see the result  
- Press C to clear the display
